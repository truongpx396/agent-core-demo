# to a version `langgraph-checkpoint-postgres==2.0.25` (requirements.txt)
# explicitly conflicts with (`<3.0.0`) — verified directly, and had to be
# fixed by rebuilding that venv from requirements-lock.txt after finding
# it. `garak/run_ci_scan.py`/`make garak`/`make garak-full` must run from a
# SEPARATE environment, never `pip install`ed alongside this app's own
# pinned LangGraph/LangChain stack.
