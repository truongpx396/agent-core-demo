domain: ecorp
title: Security awareness rules
---

Everyone must store passwords in the company password manager and never reuse them. Multi-factor authentication with a hardware security key is required for the admin console and the code repository. Suspected phishing is reported by forwarding the message to the phishing mailbox without clicking anything. A lost or stolen device must be reported to IT Security within 1 hour so it can be wiped remotely.

Customer data may only be stored on company-managed systems; copying it to personal cloud storage or a personal laptop is a policy violation that is reported to the security team. Screens must be locked whenever a device is left alone, and automatic lock is set to 5 minutes. Visitors are signed in at reception and wear a visitor badge, and they are never left alone in the office. Security training is repeated every year.
