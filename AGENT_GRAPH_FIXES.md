# Agent graph fixes: record of the 2026-10-15 review

From a review of `app/agent/` at commit `96092f7`. Every bug below was reproduced against the real graph with fake LLMs, and each regression test failed on `96092f7` with the assertion its bug predicts.

**Status:** Parts A and B and Part C items 1–7 are merged, and each fix has a "Bug:" bullet under the pattern that owns it in [GRAPH_PATTERNS.md](GRAPH_PATTERNS.md). This file was the work order for two PRs and is kept as a record; **it can be deleted**. The one open item is Part C item 8, the LangGraph upgrade, scoped in GRAPH_PATTERNS.md "Next PR: the LangGraph upgrade".

## Rules the fixes followed

- **No `STATE_SCHEMA_VERSION` bump.** No State key was renamed or removed; the only topology change (B4) moved pre-loop nodes, and a paused thread sits at `human_approval`, whose edges didn't change. A bump would have made every currently paused approval unresumable.
- Each fix: regression test first (seen failing), then the fix, a `fix:` commit stating the failure mode and root cause, and a "Bug:" bullet in GRAPH_PATTERNS.md. Two PRs of ~400–600 lines each, branched from `main`.
- The test fakes (`_scripted_llm`, `_queue_llm`, `_call`, `_orphan_tool_call_ids`, a minimal `DomainPlugin`) are defined per test module in `tests/agent/`; the `tests/conftest.py` autouse fixtures (search, cache, moderation, Postgres, pricing) apply.

## Part C: follow-up refactors

Items 1–7 are merged; item 8 is open.

1. An `OutputCheck` registry replaces the ~7 per-check `State` flags (one new check was edits in 6–7 places). → GRAPH_PATTERNS.md 5.
2. One graph builder with a profile (`GraphProfile`) instead of near-duplicate `build_graph`/`build_subagent_graph`; one tool-batch guard node; `ToolNode` wrapped in `_instrumented`.
3. Module layout: `State`, its reducers and the constants in a leaf `graph/state.py`; `GraphDeps` and the shared parts in `build.py`; Ecorp's prompt and tools moved to `app/domains/ecorp/`; one frontmatter loader for `skill_catalog` and `subagent_catalog`; no deferred-import cycles.
4. `GraphDeps` injection replaces test monkeypatch seams (`interrupt`, model alias, LLM factory) and the re-exports kept only for monkeypatching.
5. The system prompt is no longer stored in the thread (supersedes A3's patch; pattern 19).
6. `runtime/legacy_stream.py` (unused, lacked the budget checks, pending-approval check and token filter) and `recall_memories` (no production caller) deleted; "split for file size" history stripped from docstrings.
7. Performance: `suggest_followups` and `write_semantic_cache` run in parallel; `gather_context` runs the document and memory searches with `asyncio.gather`.
8. **Open:** upgrade LangGraph to 1.x (pinned `<0.3`, installed 0.2.76). Scoped in GRAPH_PATTERNS.md "Next PR: the LangGraph upgrade" (ceiling 1.0.1). It clears the import-time "incompatible versions of langgraph and checkpoint-postgres" warning; the `saver.lock = asyncio.Semaphore(...)` workaround in `runtime/core.py` needs re-checking; it needs `test-integration` and `test-live`.
